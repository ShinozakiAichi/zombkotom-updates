# Исходник опыта с фермой

`TreeFarmProbe.java` — использованный частный клиентский стенд. `validation.json` — итог двух нативных фаз. Эти файлы не входят в индекс Packwiz и не являются модом для установки игрокам.

Стенд активируется только в профиле `ZombKotom-Quest-QA` при наличии `minecraft/treefarm-qa.enabled`. Значение `first` строит ферму; `resume` проверяет прежнюю конструкцию после перезапуска. Для сборки нужны API установленного Minecraft, NeoForge и Create с вложенными зависимостями. Это исходник доказательства, а не автономный тестовый пакет.

Использовать только одноразовый мир: первая фаза очищает площадку вокруг `(416,70,416)`, обе меняют время/скорость роста, перемещают игрока и завершают клиент. Дополнительное восстановление тестового инвентаря и архивирование выполнены отдельным локальным проверочным скриптом; исходник сам не восстанавливает подобранные предметы.

Проверенная геометрия относительно механического подшипника `(0,0,0)`:

- Подшипник направлен вверх; водяное колесо находится в `(-10,-1,0)` и направлено на восток.
- Девять валов с осью X соединяют колесо с редуктором под подшипником; ось редуктора Z.
- Источник воды — в `(-10,2,-1)`. Вода подаётся после настройки фильтра руки.
- Слизь: `(0,1,0)`, ряд от `(-3,2,0)` до `(4,2,0)`, затем `(-3,3,0)`, `(-3,4,0)`, `(-4,4,0)`.
- Пила: `(4,1,0)`, режущая сторона на север при полученном вращении +8 об/мин.
- Рука: `(-4,3,0)`, направлена вниз, фильтр дубового саженца; её рабочая точка находится на высоте 1.
- Сундук: `(0,2,1)`, начальный запас 64 саженца и семь контрольных алмазов.
- Земля на высоте 0: смещения X/Z `(4,0)`, `(3,3)`, `(0,4)`, `(-3,3)`, `(-4,0)`, `(-3,-3)`, `(0,-4)`, `(3,-3)`.

Этот каркас из слизи упрощает воспроизводимость опыта. Он не предлагается как наиболее дешёвый или эстетичный проект для выживания. Механика соединения деревянного каркаса клеем требует собственного аккуратного построения по Ponder.
