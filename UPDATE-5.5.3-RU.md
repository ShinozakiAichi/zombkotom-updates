# LAST BASTION 5.5.3 — читаемая книга и исправление городов

В 160 описаниях появились разделения между абзацами. 50 длинных уроков разбиты на 2–3 страницы с кнопками перелистывания. Текст, все 165 квестов, условия, награды, зависимости и их ID сохранены: прогресс команды не сбрасывается.

Исправлена очистка устаревших данных сундуков и спавнеров после массовой генерации Lost Cities. Теперь запись удаляется, если итоговый блок вообще не поддерживает block entity (например, каменные кирпичи). Содержимое действующих сундуков и сами блоки исправление не изменяет. Мод совместимости обновлён с 1.3.0 до 1.3.1. Размер и частота городов в этом выпуске не менялись.

## Проверки

- Ошибка воспроизведена на 1.3.0: при замене сундука камнем через генератор оставалась запись сундука.
- На 1.3.1 удалены загруженная запись сундука и ожидающая запись спавнера; соседний сундук сохранил три контрольных алмаза.
- Два запуска тестового сервера завершились штатно: 212 и 182 успешных утверждения, без провалов. Это число утверждений, а не отдельных игровых сценариев.
- В 88 выбранных чанках около двух городов найдены 59 контейнеров с таблицами лута сборки. После перезапуска совпали контрольные суммы блоков и количество таких контейнеров; таблицы доступны в реестре. Выпадение каждого предмета и все типы зданий отдельно не проверены.
- Клиент открыл 23 главы и 83 выбранных квеста, включая все многостраничные: получено 304 снимка без ошибок захвата. Вручную просмотрено 11 снимков новых страниц. Это проверка интерфейса, не полное прохождение кампании.

## Установка

Для профилей с автообновлением достаточно обычного запуска Pinecone. Перед обновлением сохраните и закройте Minecraft. Личные миры, шейдеры, настройки и карты обновлятор сохраняет; установленный пользователем лимит памяти не меняется.

Для новой установки импортируйте **ZombKotom-AutoUpdate-Pinecone.zip** в Pinecone. **ZombKotom-AutoUpdate-Setup.zip** нужно распаковать и запускать из него Enable-AutoUpdate.cmd только для подключения уже существующего профиля; этот ZIP нельзя импортировать как сборку.

Проверки голоса, поездки с пассажиром, осады с реальными клиентами, FPS/MSPT и полного баланса ста ночей ещё не завершены. Этот выпуск не объявляется окончательной проверкой всех механик сборки.
