# ZombKotom / LAST BASTION — обновления

Minecraft 1.21.1 · NeoForge 21.1.257 · Java 21 · выпуск 5.5.0.
165 заданий, 23 главы, обучение работающим механизмам и рубежи кампании: [что изменилось](QUESTS-5.5-RU.md). Дроны и полезная нагрузка: [инструкция](DRONES-RU.md). Лаунчер остаётся Pinecone.

## Для друзей с уже установленной сборкой

1. Скачайте **ZombKotom-AutoUpdate-Setup.zip** из [последнего выпуска](https://github.com/ShinozakiAichi/zombkotom-updates/releases/latest) и распакуйте.
2. Сохраните мир, закройте Minecraft и полностью выйдите из Pinecone, включая значок в трее.
3. Запустите `Enable-AutoUpdate.cmd`. Скрипт найдёт стандартную папку ZombKotom; если её нет, попросит путь к папке экземпляра с `instance.cfg`. При другом расположении можно вызвать `Enable-AutoUpdate.cmd -InstanceDirectory "D:\Pinecone\instances\ZombKotom"`.
4. Откройте привычный Pinecone и нажмите «Играть». При первом подключении обновлятор сверит сборку и может заново скачать моды. Следующие запуски забирают изменения опубликованного выпуска.

Первую установку можно сделать импортом **ZombKotom-AutoUpdate-Pinecone.zip** через «Добавить сборку → Импорт из ZIP». Этот профиль скачает моды при первом запуске. Для существующего мира используйте установщик выше, чтобы продолжать в том же экземпляре.

## Что обновляется

- Моды, квестовая книга, рецепты, общие конфиги, генерация, лут и прогрессия ночей.
- Только версии, зафиксированные в опубликованном выпуске. Новейшие версии отдельных модов самостоятельно не подбираются.
- ParCool и его аддон из старой v5.2 переносятся в локальную резервную папку при первом успешном обновлении.

## Личное остаётся личным

**Папка `shaderpacks` полностью исключена из автообновления.** Любые добавленные другом ZIP, распакованные пакеты и файлы настроек останутся. `config/iris.properties` тоже исключён: выбор шейдера и его включение не сбрасываются.

Не обновляются `options.txt`, управление, настройки Sodium, миры `saves`, карты, скриншоты и аккаунты. Клиентские настройки, перечисленные в `POLICY.md`, также не управляются Packwiz. Начальные настройки копируются установщиком только если соответствующего файла ещё нет. При первом запуске отсутствующий стандартный шейдер скачивается с Modrinth; существующие файлы не заменяются.

Стандартный шейдер — **[Complementary Reimagined](https://modrinth.com/shader/complementary-reimagined)** от [Complementary Development](https://www.complementary.dev/), r5.9.3, исходный ZIP без модификации. За совместимость шейдера с этой сборкой отвечает автор сборки. Шейдер не перезаливается в релиз: загрузка идёт с официального Modrinth CDN.

Изменение генерации влияет на новые чанки. Обновление книги не заменяет сохранённый прогресс мира. Подготовка выпуска должна сохранять существующие ID квестов.

## Если обновление не удалось

Игра не запускается с частично применённым обновлением. Повторите запуск после восстановления соединения. Диагностика находится в `minecraft/lastbastion-update.log` и консоли лаунчера. Перед сменой опубликованного выпуска сохраняются локальные копии `config` и `packwiz.json` в `minecraft/update-backups/auto-*`. Это резервная копия конфигов, а не полный откат всех модов или мира.

Для отключения автообновления: настройки экземпляра → пользовательские команды → очистить команду перед запуском. Файлы игры сохраняются. Не отключайте обновление только на одном компьютере перед совместной игрой с другой версией.

## Публикация

Packwiz читает [pack.toml](https://shinozakiaichi.github.io/zombkotom-updates/pack.toml). GitHub Pages публикует ветку `main`. Локальные правки в рабочей сборке сами к друзьям не отправляются: для выпуска нужны проверка, пересборка индекса и явная публикация в `main`.

113 модов загружаются с Modrinth, 3 FTB-мода и FPVCraft с официального CurseForge CDN; здесь хранится только собственный небольшой патч совместимости. Minecraft, личные сохранения и данные аккаунтов в репозиторий не включены.

Используются [packwiz-installer 0.5.14](https://github.com/packwiz/packwiz-installer/releases/tag/v0.5.14) и [bootstrap 0.0.3](https://github.com/packwiz/packwiz-installer-bootstrap/releases/tag/v0.0.3). Обновление самого установщика зафиксировано отдельно от игрового содержимого.
